# V2.2A structured-claim evaluation protocol

This directory is separate from frozen Step 13 and Step 18H material. Cases
must be versioned as development or held-out before use, and controlled cases
must be labelled synthetic. Metrics include normalized field precision/recall,
exact span overlap, claim-count accuracy, missed claims, and hallucinated
claims. No real-provider metric is published until a provider is configured
and evaluated on the same held-out cases as the deterministic baseline.
