# V2.2A Evaluation

Evaluation uses a new, separate V2.2A corpus with a development/held-out split
declared before tuning. It distinguishes source-derived and controlled cases.

span-overlap, invalid-output, fallback, claim-count, missed-claim, and
hallucinated-claim metrics. Compare deterministic, provider, and hybrid modes
only on the same held-out cases. Real provider evaluation is pending.
